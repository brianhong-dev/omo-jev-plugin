# Security policy

## Reporting a vulnerability

Please [report security issues privately through GitHub](https://github.com/brianhong-dev/omo-jev-plugin/security/advisories/new), not through public issues or pull requests. Include affected versions, reproduction steps, and the potential impact. Do not post API keys or private prompts.

We will acknowledge the report and coordinate a fix and disclosure with the reporter. We do not promise a fixed response or release timeline.

## Supported versions

Security fixes target the latest published version. Older versions are not maintained separately.
